│  json_to_dart_library: ^0.0.7                                              │
│                                                                             │
│  DartObject.checkError(String className) {                                 │
│    // Pseudo-code (actual logic in library)                               │
│                                                                             │
│    1. Get new className value                                             │
│    2. Clear previous errors from _classError                              │
│    3. Iterate through allObjects                                          │
│       for each DartObject in allObjects {                                │
│         if (other.className == this.className &&                          │
│             other != this) {                                             │
│           // Duplicate found!                                            │
│           _classError.add(                                               │
│             FFJsonToDartConfig.duplicateClasses                          │
│           )                                                              │
│         }                                                                │
│       }                                                                  │
│    4. Update hasClassError property                                      │
│  }                                                                        │
│                                                                             │
│  where allObjects is maintained by JsonToDartControllerMixin              │

│      }                                                                    │

================================================================================
                            COMPLETE FLOW SEQUENCE
================================================================================

[1] User types JSON in editor
    ↓
[2] User clicks "Format" button
    ↓
[3] formatJsonAndCreateDartObject() called
    • allObjects.clear()
    • allProperties.clear()
    ↓
[4] JSON parsed and DartObject tree created
    • dynamicToDartObject() populates allObjects
    ↓
[5] UI displays JSON tree with editable class names
    ↓
[6] User changes a class name in the UI
    ↓
[7] onChanged handler triggered
    property.className = newValue
    property.checkError(newValue)
    ↓
[8] checkError() method from library executes
    • Iterates through allObjects
    • Compares className with all other objects
    • If duplicate found: adds error to _classError
    ↓
[9] Reactive UI updates (Obx wrapped components)
    • Icon changes from blue to red
    • Tooltip shows error message
    • hasClassError property becomes true
    ↓
[10] User clicks "Generate" button
     ↓
[11] generateDartCode() validation checks
     • Searches allObjects for any element with hasClassError
     • If found: shows error dialog and returns null
     • Generation is blocked
     ↓
[12] If no errors exist, code generation proceeds
     • Dart code is formatted
     • Result copied to clipboard
     • Success message shown
